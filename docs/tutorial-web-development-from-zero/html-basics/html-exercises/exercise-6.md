# Ejercicio práctico HTML 6

## Objetivo

Tablas

### Actividad

Crea una tabla con tres filas y tres columnas usando la etiqueta `<table>`.

### Solución

```html title="html"
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Tablas</title>
  </head>
  <body>
    <h2>Tabla</h2>
    <table border="1">
      <tr>
        <th>Encabezado 1</th>
        <th>Encabezado 2</th>
        <th>Encabezado 3</th>
      </tr>
      <tr>
        <td>Fila 1, Columna 1</td>
        <td>Fila 1, Columna 2</td>
        <td>Fila 1, Columna 3</td>
      </tr>
      <tr>
        <td>Fila 2, Columna 1</td>
        <td>Fila 2, Columna 2</td>
        <td>Fila 2, Columna 3</td>
      </tr>
    </table>
  </body>
</html>
```
