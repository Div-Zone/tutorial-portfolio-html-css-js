# Ejercicio práctico HTML 3

## Objetivo

Párrafos y Enlaces

### Actividad

Crea un documento HTML con varios párrafos `<p>` y enlaces `<a>` que apunten a diferentes sitios web.

### Solución

```html title="html"
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Párrafos y Enlaces</title>
  </head>
  <body>
    <p>
      Este es un párrafo.
      <a href="https://www.google.com" target="_blank">Google</a>
    </p>
    <p>
      Otro párrafo con un
      <a href="https://www.bing.com" target="_blank">enlace a Bing</a>
    </p>
  </body>
</html>
```
