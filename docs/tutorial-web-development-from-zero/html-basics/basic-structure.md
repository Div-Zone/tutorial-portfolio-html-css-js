# Estructura básica de un documento HTML

Todo documento HTML comienza con la declaración `<!DOCTYPE html>` seguida por la etiqueta `<html>`. Dentro de esta etiqueta, tenemos dos secciones principales: `<head>` y `<body>`.

```html title="html"
<!DOCTYPE html>
<html>
  <head>
    <title>Mi primera página web</title>
  </head>
  <body>
    <h1>¡Hola, mundo!</h1>
    <p>Este es mi primer documento HTML.</p>
  </body>
</html>
```

`<!DOCTYPE html>` Esta declaración define el tipo de documento y la versión de HTML que se está utilizando. `<html>` Es la raíz del documento HTML. `<head>` Contiene meta-información sobre el documento, como el título y enlaces a hojas de estilo o scripts. `<title>` Define el título del documento que aparece en la pestaña del navegador. `<body>` Contiene la parte visible de la página web, como encabezados, párrafos, imágenes, enlaces, etc.
