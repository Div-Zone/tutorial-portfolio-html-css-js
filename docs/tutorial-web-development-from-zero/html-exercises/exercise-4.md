# Ejercicio práctico HTML 4

## Objetivo

Listas Ordenadas y Desordenadas

### Actividad

Crea un documento HTML con una lista ordenada (`<ol>`) y una lista desordenada (`<ul>`).

### Solución

```html title="HTML"
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Listas</title>
  </head>
  <body>
    <h2>Lista Ordenada</h2>
    <ol>
      <li>Elemento 1</li>
      <li>Elemento 2</li>
      <li>Elemento 3</li>
    </ol>
    <h2>Lista Desordenada</h2>
    <ul>
      <li>Elemento A</li>
      <li>Elemento B</li>
      <li>Elemento C</li>
    </ul>
  </body>
</html>
```
