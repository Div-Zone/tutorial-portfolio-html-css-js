# Ejercicio práctico HTML 15

## Objetivo

Enlaces de Descarga

### Actividad

Crea un enlace que permita descargar un archivo.

### Solución

```html title="HTML"
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Enlace de Descarga</title>
  </head>
  <body>
    <h1>Descargar Archivo</h1>
    <a href="archivo/mi_documento.pdf" download>Descargar PDF</a>
  </body>
</html>
```
