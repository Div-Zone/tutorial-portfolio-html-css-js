# Ejercicio práctico HTML 1

## Objetivo

Crear un Documento HTML Básico

### Actividad

Crea un archivo HTML básico con la estructura mínima `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`.

### Solución

```html title="HTML"
<!DOCTYPE html>
<html>
  <head>
    <title>Documento HTML Básico</title>
  </head>
  <!-- Este es un comentario HTML  -->
  <body>
    <h1>Hola, Mundo!</h1>
  </body>
</html>
```
