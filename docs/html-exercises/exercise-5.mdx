# Ejercicio práctico HTML 5

## Objetivo

Imágenes

### Actividad

Crea un documento HTML que incluya una imagen usando la etiqueta `<img>`.

### Solución

```html title="HTML"
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Imágenes</title>
  </head>
  <body>
    <h1>Imagen</h1>
    <img src="https://via.placeholder.com/150" alt="Imagen de ejemplo" />
  </body>
</html>
```
