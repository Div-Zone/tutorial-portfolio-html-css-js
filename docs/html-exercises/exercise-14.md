# Ejercicio práctico HTML 14

## Objetivo

Comentarios en HTML

### Actividad

Añade comentarios en un documento HTML.

### Solución

```html title="HTML"
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Comentarios</title>
  </head>
  <body>
    <!-- Este es un comentario en HTML -->
    <p>Este párrafo está visible.</p>
    <!-- <p>Este párrafo está comentado y no se verá.</p> -->
  </body>
</html>
```
