# Ejercicio práctico HTML 10

## Objetivo

Enlaces con Imágenes

### Actividad

Crea un documento HTML donde una imagen sirva como enlace.

### Solución

```html title="HTML"
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Enlaces con Imágenes</title>
  </head>
  <body>
    <h1>Enlace con Imagen</h1>
    <a href="https://www.google.com" target="_blank">
      <img src="https://via.placeholder.com/150" alt="Google" />
    </a>
  </body>
</html>
```
